# 回答テンプレートとURL参照ルール
 
このファイルには、fusionplace が回答を作成する際に使う「パターンA/B/C」の具体的なテンプレート文言と、参照URLの精度・フォールバックに関する詳細ルールが記載されています。
 
**読み込むタイミング**: SKILL.md の Step 4（回答を作成する）に進んだとき、実際に回答文を組み立てる直前に読み込むこと。Step 1〜3（質問分析・検索・自己チェック）の段階では不要。
 
---
 
## 回答パターンのテンプレート
 
回答は以下の4パターンのいずれかの形式を基本とする。どのパターンを使うかの判断基準はSKILL.mdの「Step 4」に記載されている。ここでは各パターンの具体的な文言テンプレートのみを示す。
 
### パターンA：ドキュメントに記載あり（推論不要）
 
```
【マニュアルより】/ 【Q&Aより】/ 【パターンライブラリより】
〜（公式ドキュメントに直接記載されている内容のみ）〜
参照：https://...
複数ページを参照した場合は参照URLを列挙する
```
 
### パターンB：ドキュメントに原則・概念は記載があるが、具体的な手順・詳細は記載なし
 
```
【マニュアルより】/ 【Q&Aより】/ 【パターンライブラリより】
〜（ドキュメントに明記されている原則・概念）〜
参照：https://...
複数ページを参照した場合は参照URLを列挙する
 
---
【推論による補足】
マニュアルには具体的な操作手順の記載が見当たりませんでしたが、
上記の原則をもとに以下のように考えられます：
〜（推論・応用による補足。断定を避け「〜と考えられます」等を使う）〜
```
 
### パターンC：ドキュメントに該当情報なし（客観的事実の欠落時のみ）
 
```
公式ドキュメントには該当情報が見当たりませんでした。
有償版をご利用のお客様は、詳細について [公式サポート]( https://docs.fusionplace.net/qanda/ja/procedures.html ) にお問い合わせください。
```
 
- 「有償版をご利用のお客様は、」という文言を必ず入れる
- **注意**: パターンCの使用条件（客観的事実の欠落時のみ使う、業務・設計相談型には使わない等）は SKILL.md の「共通ルール（サマリ）」を参照。ここでは文言テンプレートの提示のみを行う。
---
 
## URL参照の精度とフォールバックルール
 
参照URLの基本ルール（`link` を使うこと・`detail_url` を提示しないこと・記憶や推測でURLを組み立てないこと）は SKILL.md の「共通ルール（サマリ）」を参照。ここでは、その基本ルールを満たしつつ個別ページのURLが確認できない場合のフォールバック手順のみを示す。
 
- 内容は見つかったが、そのページの個別URLが検索結果・取得結果から確認できない場合、確認できないURLをそのまま案内しない。代わりに、該当カテゴリのトップページ（一覧ページ）を代替として案内する
  - 例：仕様・制限に関する内容であれば、仕様／制限カテゴリの一覧ページ
  - 該当する一覧ページも特定できない場合は、ソースの基準URL（ユーザーマニュアル: `https://docs.fusionplace.net/manual/ja/` 、Q&A: `https://docs.fusionplace.net/qanda/ja/` 、パターンライブラリ: `https://docs.fusionplace.net/patterns/ja/` ）を代替として案内する
- 代替案内をする場合は、個別ページの直接リンクではなく一覧ページ／トップページである旨を必ず明示する（例：「該当ページの直接URLは確認できなかったため、以下のカテゴリ一覧ページから探索してください」）
- このルールは「情報自体は見つかったが、確実なURLが確認できない」場合に適用するものであり、パターンC（該当情報自体が見当たらない場合）とは別軸である
